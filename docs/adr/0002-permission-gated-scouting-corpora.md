# 对球探 RAG 语料实施许可门控并分开检索

公开网页可读并不等于允许自动抓取、持久索引或 AI/RAG 处理。TactiScout 用来源许可登记门控入库，并把方法资料与球员报告分开检索：前者辅助建立目标能力画像；结构化候选筛选和比赛数据评估之后，后者才补充定性线索。报告引出的新名字可以回到结构化数据核验。服务端用 LanceDB 本地持久索引，默认用本地 multilingual E5 生成向量，与浏览器招募计划存储分开。PLOS 官方 Search API 只发现文章元数据；正文采集是单独的、限制到登记 DOI 的命令，并要求 API 返回 CC BY 许可声明。当前登记一篇方法论文和一个仅接收用户自录笔记的第一方来源；尚无获准的外部具名球员报告语料。球探观察记录逐条征得本地保存和 AI/RAG 处理许可，参考链接不会被抓取。这样能让来源、许可和推荐依据可追溯，也避免 MVP 默认把第三方报告正文发给模型。
