# Issue 36: FBref 五大联赛当前表现数据源

Type: task
Status: claimed
Labels: ready-for-agent
Blocked by: none

## Goal

为 TactiScout 增加 FBref 当前五大联赛球员表现 provider，并接入现有 PlayerRepository 和 LangGraph 调查链路。用户明确选择 FBref，并接受公开页面抓取作为个人作品集原型的数据接入方式；项目不得绕过登录、验证码、403/429 或其他访问限制。

## Scope

- 使用语义列名解析标准、传球、防守和持球统计页；不依赖列序号。
- 以 FBref 球员 ID、球队 ID 和赛事 ID 组合赛季记录身份；保留球队间的转会记录，不按姓名合并。
- 只映射页面有实际数值的字段。当前模式以出生日期计算抓取日年龄，位置保持 GK/DEF/MID/ATT 等宽泛分类。
- 当前赛季 Big 5 页面包含英超、西甲、德甲、意甲、法甲；不得称为完整注册名单或完整转会市场。
- 先读取标准页，再将其他统计页串行读取且请求至少间隔 1 秒；成功快照缓存 24 小时，任一页面遇到 403/429 后停止本轮剩余请求并缓存该拒绝 24 小时；不存在备用隐藏接口、身份轮换或挑战绕过。
- 位置未知的记录不能默认标成前锋；无单一球队 ID 的多队汇总记录不能当作球队候选，且须在来源说明中披露排除情况。
- 报告和球员卡显示数据范围、抓取时间及可打开的来源页；缺失指标保持不可用。
- README 和 `.env.example` 说明配置、字段边界及无 API/非完整覆盖限制。

## Acceptance criteria

- `TACTISCOUT_DATA_MODE=fbref` 可运行现有对话式 LangGraph 候选查询、球队检查和按 ID 评估。
- 来源映射保留 FBref 原始球员页、来源 ID、抓取时间、赛事和赛季。
- 标准表是必需数据；可选统计页缺失时只降低该页所覆盖的字段，不把空字段转成零值或停止已有候选池。
- 抓取错误明确区分网络错误、403 拒绝和 429 限流；不自动重试。
- 任一请求遇到 403/429 后，不再请求同一批次剩余页面；未知位置和多队汇总记录不得静默误分类。
- UI 和报告明确写出五大联赛及“表现记录池，不是完整现役名单”的范围。
- 前后端生产构建通过。
