# Wyscout 渐进传球事件派生证据

Type: task
Status: resolved
Labels: ready-for-agent

## Goal

让 Wyscout 2017/18 事件样本提供带明确定义与假设的方向推进证据，补足目前只有传球次数和关键传球、缺少直接推进维度的能力评估。

## Research basis

Wyscout 官方渐进传球词典使用起点与下次触球位置计算向对方球门靠近的距离：同在本方半场至少 30 米、跨越中线至少 15 米、同在对方半场至少 10 米；传球成功以队友完成下次触球定义。Wyscout v2 事件文档将位置坐标定义为进攻方向百分比，并记录起点/终点；标签 1801/1802 分别表示成功/失败。2017/18 开放样本没有现成渐进传球字段，因此 TactiScout 只能用坐标近似计算，并明确写出将 100 坐标点换算成 105 米的假设。官方定义与字段见 [渐进传球词典](https://dataglossary.wyscout.com/progressive_pass/) 和 [Wyscout v2 事件文档](https://support.wyscout.com/matches-wyid-events)。

## Acceptance criteria

- [x] 增加 Wyscout 专属的“渐进传球（推算）/90”与“渐进传球成功率（推算）”证据键，保留定义、计算假设、来源字段、样本分钟/场次与 CC BY 数据来源。
- [x] 只使用完整事件样本、有效的起终点坐标及互斥的成功/失败标签；数据不完整时不提供指标，不能静默当作零。
- [x] 使用官方分区阈值，推算字段与来源原生统计明确区分；旧赛季范围和估算出场分钟限制在 Agent 与报告中可见。
- [x] 派生指标只进入可追溯证据，不能自动进入现有职责评分公式。
- [x] README、CONTEXT、案件 Agent 指令与 issue map 一致描述指标语义和限制。

## Answer

已实现两个来源专属的补充指标。Provider 仅在球员出场所对应的事件文件完整、所有传球都带有效起终点 x 坐标和互斥的成功/失败标签时输出；否则省略整个推算指标，避免不完整数据被误当作零。使用 Wyscout 的三个距离分区阈值，将 100 个坐标点按 105 米场地长度假设换算；估算出场分钟用于 /90 归一化。指标进入 LangGraph 可引用的证据列表和报告展示，不进入现有规则职责评分。

API TypeScript 构建、Web TypeScript/Vite 生产构建和 `git diff --check` 通过；本轮未运行自动化测试。
