# Agent Harness 行为评估套件

Type: task
Status: resolved
Labels: ready-for-human

## Goal

为 TactiScout 的自然语言球探案件建立可重复的行为评估：固定代表性场景，检查模型驱动的工具编排、追问恢复、证据边界和已知数据限制，并能通过重复运行暴露随机性。

## First-principles boundary

- 本轮只评可由数据集、接口契约或明确项目规则判定的行为不变量；不把单次成功或 LLM judge 输出说成球探质量证明。
- 演示球员集没有正确排序标签，因此不测 NDCG、Top-k 命中率或推荐准确率，不引入臆造的综合分。
- 当前获准方法资料只有一篇，具名球员报告语料为空；方法检索的 reachability 可以检查，但暂不宣称有足够标注计算 RAG 相关性/召回率。
- 代表性场景至少覆盖：有明确位置的巴萨年轻中场需求；凯恩接班人需求需先查证、在关键角色歧义处追问、补答后同案续查；演示数据缺少中锋时不得跨位置凑推荐。
- Trace 可记录动作名、真实结构化筛选范围（不含自由文本姓名/查询）、调用结果数量、耗时和候选 ID；不得输出隐藏推理、原始对话或模型凭据。

## Public seam

继续使用 `pnpm eval:local-agent` 作为本机真实模型的外部验收入口。默认行为与现有单场景用法兼容；新增具名场景、全场景运行及有限次数的重复运行。场景契约和纯评估逻辑由 runner 与确定性测试共用。

## Acceptance criteria

- [x] 评估数据集以稳定 ID 描述用户输入、可选补答和每场景的硬性期望；场景描述不把具体的推荐球员或排序当作真值。
- [x] CLI 可单独运行标准场景、接班人追问场景或全量数据集；可设置 1–10 次重复运行，每次使用独立案件 ID。
- [x] 每次运行给出通过/失败检查及不含隐藏推理、原始查询和球员姓名的工具轨迹；总体摘要给出通过比例、失败检查及 p50/p95 耗时。
- [x] 每场景评估是否遵守目标球队/筛选边界、必要工具与评估阶段、调查后追问、同一 thread 恢复、已声明的位置约束、证据支持，以及空数据时诚实等待或报告限制。
- [x] 对推荐排序准确性明确输出“不评估：缺少可信标签”，不能将空索引/空候选误记为相关性失败或能力低分。
- [x] 可用独立已知 trace 证明所有关键条件一旦违反就失败；测试通过 evaluator 的稳定调用接口，不访问真实模型服务。
- [x] Ollama 配置可用时，运行全量场景一次并记录实际耗时与各硬性检查；不得把单次通过描述成可靠性/统计显著性结论。

## Adversarial review questions

- evaluator 是否只是把当前 prompt 和同一模型输出复述成“期望”，导致自我验证的循环论证？
- 某场景若没有可用球员、没有球员报告或正确结果是继续追问，检查能否区分“诚实停下”和“任务失败”？
- 重复运行是否真正创建独立案件，是否会错误地把先前 checkpoint 或上一轮 trace 带入？
- 汇总通过率是否会掩盖某一条关键安全不变量在一次运行中的失败？
- 隐私检查是否覆盖 stderr trace 和 JSON 结果的每一条输出路径，而不是只检查成功摘要？

## Answer

已完成全 TypeScript 的行为评估套件，包括固定代表场景、同案追问续跑、1–10 次独立案件重复、通过率与 p50/p95 耗时、证据 ID 轨迹、隐私净化，以及确定性合成轨迹测试。评估强制检查成功候选搜索先于评估，且评估 ID 必须来自工具实际发现的候选；角色追问检查只读取用户可见问题，不用解释字段里的关键词代替实际问题。它不评估球员排序正确性或当前小语料的 RAG 相关性。

## Comments

### 2026-10-04 — 空位置结果后的真实模型回归

本机 `qwen3.5:9b` 复跑发现，拜仁场景在用户确认中锋后得到 0 个候选，LangGraph 仍把下一步交给模型；模型再次以 `offset: 10` 查询空结果并重复提出不合适的问题，最终触发策略循环保护。根因是已记录的 `confirmedPositionSearchMatchCount === 0` 没有对应的确定性分支。

已修复：空结果现在先询问是否扩大位置范围；用户保留原位置时直接完成并如实说明无样本；用户同意扩大到其他前锋位置时，`ATT` 位置族约束会覆盖检索、评估、证据审核与推荐。拒绝扩大位置的回答不再被解析成同意扩大。

快速回归：新增同案追问测试覆盖询问、拒绝后结束，以及扩大至其他前锋位置并推荐匹配位置族球员。`node --import tsx --test tests/*.test.ts` 104/104 通过；API 和网页 TypeScript 检查、网页生产构建通过。

修复后的本机 Ollama 全量运行：`barcelona-under-23-midfielder` 61.7 秒，全部硬性检查通过；`bayern-kane-replacement` 32.0 秒，全部硬性检查通过，角色确认后中锋搜索从 offset 0 返回空，再停在清晰的范围选择问题。每场景一次只验证本次运行的行为，不证明长期稳定性、推荐准确率或真实球员数据质量。
