# 把球探调查进度做成可读的阶段时间线

Type: task
Status: resolved
Labels: ready-for-agent

## Goal

让用户在本地模型耗时较长时看得懂 Agent 正在做什么、已经经过哪些调查环节，并且不显示伪造的百分比、预计完成时间或模型内部推理。

## Acceptance criteria

- [x] 服务端按案件记录本轮实际发生的公开调查阶段；事件最多保留 12 条，每次新请求重新开始，不跨轮次泄漏。
- [x] 对话等待卡展示当前阶段、最近已完成阶段与经过时间，不只显示旋转图标和一句状态文字。
- [x] 阶段轨迹来自 LangGraph 的受控状态消息，不包含球员姓名、用户原文、prompt、模型推理或凭据。
- [x] 进度轮询暂时失败时，启动提示和计时仍可读；恢复后展示服务端真实阶段。
- [x] 不显示缺乏依据的百分比、ETA 或“决策步数”；结论合成与推荐复核分阶段显示，重复执行带有次数标记。
- [x] 布局在窄屏可读，当前状态可由辅助技术读取，动画尊重 reduced-motion 设置。
- [x] README、`CONTEXT.md`、map 与本 issue 说明进度只代表流程阶段，不代表质量、推荐置信度或完成比例。

## Answer

Fastify 每次案件轮次记录最多 12 条实际进度事件，给重复阶段附加该阶段的出现次数；新一轮请求从空事件列表开始。LangGraph 把证据汇总与最终证据复核拆为不同的进度阶段。React 等待卡将最近阶段显示为时间线，突出当前环节与耗时，不再只显示 spinner 或 Agent 决策步数；轮询连接中断时保留现有轨迹和计时，并说明更新暂不可用。小屏宽度、辅助技术当前状态播报与减少动态效果均已处理。

验证：API `pnpm build`、Web `pnpm build:web`、`git diff --check` 通过。本轮未运行自动化测试。
