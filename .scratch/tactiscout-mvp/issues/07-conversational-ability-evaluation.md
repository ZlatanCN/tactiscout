# 以对话式能力评估与推荐为首版主线

Type: grilling
Status: resolved
Labels: wayfinder:grilling

## Question

首版应如何处理用户的一句话引援需求，哪些足球转会维度需要纳入 MVP？

## Answer

用户用自然语言描述阵容问题。Agent 先调查可用的阵容和球员表现证据，建立目标角色的能力画像，再发现、比较并推荐候选球员；遇到会显著改变能力画像、且可用证据无法解决的歧义时，提出简短问题，并在用户回答后继续同一案件。

首版重点是球员能力、角色适配、统计证据、样本风险和数据缺口。位置、年龄、预算可作为用户主动提出的辅助偏好，不要求开场填写。暂缓非欧、工作许可、注册名额等转会与联赛细则，不建立对应规则引擎。

Agent 必须区分事实与推断。当前数据源不支持核实完整现役阵容时，应说明这一点，不得把历史比赛阵容说成当前阵容。推荐应以可观察指标和可解释比较为依据；未经验证的总分不能包装成客观球员能力等级。
